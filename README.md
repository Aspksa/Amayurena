# Amayurena

Amayurena — персональное веб-пространство. Первая версия включает рабочий раздел **«Агенты»** для подготовки конфигураций будущих ИИ-агентов.

## Запуск

1. Скачайте ZIP-архив репозитория и распакуйте его.
2. Откройте `index.html` двойным щелчком в современном браузере.
3. В меню выберите **«Агенты»** и нажмите **«Создать агента»**.

Для запуска сайта не нужны Python, Node.js, сервер или права администратора.

## Возможности

- Создание, редактирование и удаление агентов.
- Имя, роль, описание и системные инструкции для каждого агента.
- Поиск по имени, роли и описанию, счётчики.
- Локальное сохранение в `localStorage` браузера (до 500 агентов).
- Резервное копирование и восстановление через JSON с проверкой содержимого и подтверждением замены.
- Светлый адаптивный интерфейс в бело-золотых тонах.

**Ограничение:** пока это каталог настроек, не исполняемые ИИ-агенты. Вызовы нейросетей, общение с агентами, их инструменты, автономная работа и обмен задачами **не подключены**. Не храните API-ключи или пароли в инструкциях агентов.

Локальные данные могут быть удалены при очистке браузера. Поведение `localStorage` при открытии `file://` зависит от браузера. Используйте **«Экспорт JSON»** для резервного копирования. При ошибке хранилища сайт сообщает, что сохранение недоступно.

## Проверки

Для разработчика с установленным Node.js:

```sh
node --check agents-core.js
node --check app.js
node --test tests/*.test.cjs
```

GitHub Actions выполняет те же быстрые проверки на PR и на основной ветке.
